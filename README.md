# Tea Table · 排版编辑器

一个无需后端的本地排版编辑器。项目数据保存在浏览器 `localStorage`，同一浏览器的不同窗口会自动同步最新修改。

## 启动

在当前目录运行：

```bash
python3 -m http.server 5174
```

然后打开 <http://localhost:5174>，默认直接进入全屏预览模式。

进入编辑器：<http://localhost:5174/?mode=editor>

## 部署到 Cloudflare

项目已配置 Cloudflare Workers Static Assets。首次部署前先登录 Wrangler：

```bash
npx wrangler login
npx wrangler deploy
```

默认 Worker 名称为 `tea-table-preview`，可在 `wrangler.jsonc` 中修改。部署后会得到一个 `*.workers.dev` 访问地址。

## 已支持

- 多页面新建、重命名、切换、删除；每页独立图层布局
- 共用美术资产库，支持 PNG/JPG/WebP/GIF 上传
- 点击素材添加到画布；拖动、缩放、旋转
- 图层上下拖动排序，隐藏、锁定、删除
- 撤销 / 重做、自动保存、预览
- 完整项目 JSON 导入 / 导出
- 多窗口通过 `BroadcastChannel` 和 `storage` 事件同步
- 预览模式支持居中的大号 `Portfolio` 字母交互：鼠标靠近时字母切换为下午茶透明图片，并产生弹性放大、上浮和邻字让位效果
- 预览模式支持茶壶入口交互：进入茶杯选择页后，五个茶杯均可点击；点击后茶壶移动到对应参考流水线并轻微倾斜对准壶嘴，随后出现对应位置的绿色茶流、杯内茶面上涨和倒茶声，动画完成后进入作品详情页
- 预览首页将左下角三张马卡龙与小盘子作为一个组合入口，悬浮时整体上浮放大，点击后进入马卡龙页面
- 马卡龙入口页的三个马卡龙支持与茶杯一致的悬浮效果；点击任意马卡龙时，左侧叉子会按参考叉子的叉头位置和角度移动，扎到目标后再进入详情页
- 预览模式的页面切换统一使用圆形遮罩扩散/收缩转场，适用于茶壶、马卡龙、详情页和返回操作
